デザインメモ

Direction C「Native macOS」— Xcode / メール / メモと並べて違和感のない CC Hub

  • コンセプト: 主役は「ひとつのウインドウで複数の Claude を見張る」こと。装飾は足さず、Xcode のアクティビティビューア(ツールバー中央のカプセル)に「いま何が起きているか」と Session / Context の使用量を集約した。
  • 文字組み: -apple-system (SF Pro + ヒラギノ角ゴ)。本文 13px / 補足 11px / ウインドウタイトル 13px Bold / セクション見出し 11px Bold。コードと branch は SF Mono 11〜12.5px。行間は会話 1.6、リスト 1.45。
  • 余白: 4px 刻み (4/8/12/16/20/24)。ツールバー 52px、ジャンプバー 28px、サイドバー行 28px(セッションは2行で約 40px)。会話は最大 720px 幅で中央寄せし、長文を読みやすくした。
  • 角丸: --radius 6px(小コントロール)/ 10px(ツールブロック・入力欄)/ 16px(シート・ウインドウ)。ツールバーのボタンとアクションボタンは macOS 26 のカプセル形。
  • 状態の色ロジック: 色は「どれだけ急ぐか」の1軸。オレンジ=人が判断しないと進まない(承認待ち)、緑=人の入力を待つ、青=進行中、赤=失敗、グレー=待機・停止。形も変えて、色が見分けにくくても判別できる(手・吹き出し・回転リング・三角・空円・四角)。
  • 承認待ちの強調: オレンジを使うのは承認待ちだけ。行の薄い塗り + 左端 2.5px のライン + 末尾カプセル、折りたたんだリポジトリにも件数バッジ、ツールバーに「承認待ち 2」。点滅や赤は使わず、静かでも見落とせない程度にとどめた。
  • HIG パターン: ソースリスト(サイドバー + 開閉三角)、統合ツールバー、Xcode 型インスペクタ(セグメンテッドコントロールでタブ切替)、ジャンプバー(cwd をパンくずで表示)、シート(承認)。どれも mac ユーザーが操作を覚えているので、学び直しが要らない。
  • シートの範囲: 承認シートは会話ペインにだけ掛け、ウインドウ全体はブロックしない。別セッションへ移っても承認は待ち続けられる。既定ボタンは安全側の「今回だけ許可」(↩)、拒否は左端(esc)。「許可」は常時許可の意味なので既定にしない。
  • 選択表示: 入力欄にフォーカスがある間、サイドバーの選択はグレー(unemphasized)。青い選択にするとオレンジの承認アイコンと重なって潰れるので、実機と同じ挙動のまま衝突も避けられる。
  • コントラスト: Apple 標準の secondaryLabel(50% 黒)は AA を満たさないため、--muted #636368 と文字専用の --accent-text / --st-approval-fg を用意。オレンジのバッジは白文字ではなく濃い茶 (--on-approval) にした。
  • Electron 側の変更: titleBarStyle: 'hiddenInset'、trafficLightPosition: {x: 18, y: 18}、vibrancy: 'sidebar'、visualEffectState: 'followWindow'、backgroundColor: '#00000000'(サイドバー以外は CSS で不透明に塗る)。ツールバーは -webkit-app-region: drag、ボタン類は no-drag。nativeTheme でダーク追従し、アクセントは systemPreferences.getAccentColor() を --accent に流し込む。
  • Web 側の変更: --sans / --mono を mac では system-ui / ui-monospace に変更。html.platform-mac のときだけトークンを差し替え、Windows 版は現行のまま残す。
