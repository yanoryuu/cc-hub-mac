デザインメモ — Direction A「Liquid Glass」

macOS 26 の HIG に沿い、ガラスは「操作の層」だけに使い、読む層は不透明に保つ。

  • コンセプト: 多数のエージェントを見守る「管制窓」。ガラスはサイドバー・ツールバー・コンポーザー・インスペクタなど浮遊する操作層に限定し、その下を流れる会話シートは不透明な紙として扱う。
  • シグネチャー「承認レンズ」: 承認待ちだけがアンバーに色付いたガラスを持つ。ツールバーのキュー、サイドバーの行、会話内カードの 3 か所が同じ素材・同じ光の筋(5 秒に 1 回)でつながり、どこにいても「ここで止まっている」と分かる。
  • タイポグラフィ: SF Pro(-apple-system)+ ヒラギノ角ゴ。11 ラベル / 12 補足 / 13 本文(macOS 標準)/ 13.5 会話 / 15 見出し / 22 画面タイトル。等幅は SF Mono 11–12。ウェイトは 400 / 500 / 600 / 700 のみ。
  • 余白: 4px グリッド(4・6・8・10・12・14・24)。ウィンドウ内側 8px、行のパディング 6×8px、会話の段落間 18px。
  • 角丸(同心円): ウィンドウ 26 → パネル 18(内側 8px)→ 行・カード 10、承認カード 18 → 内側 12(6px)。ボタンとチップはすべてカプセル型(高さの半分)。
  • 状態色: 色・形・ラベルの 3 つで表す(● 実行中 / 角丸の ‖ 承認待ち / ✎ 入力待ち / ○ 待機 / ▲ エラー / ■ 停止)。実行中は accent の青と混ざらないようティール。承認待ちは面用 --st-approval-fill と文字用 --st-approval に分け、明暗どちらでも AA を確保。
  • ガラスを使う場所: サイドバー、ツールバーのカプセル、承認キュー、コンポーザー、インスペクタ。blur(28px) saturate(180%) に、上辺 1px のライトエッジと外周 0.5px のヘアラインを重ねる。
  • ガラスを使わない場所: 会話本文、ツール出力、ターミナル(--bg-term で常に暗く不透明)、コード、差分。読む・コピーする面に背景が透けてはいけない。prefers-reduced-transparency のときは不透明色に切り替える。
  • コントラスト: ガラスの地は白 62% / 黒 58% 以上を保ち、文字は --fg / --muted のみ。--dim はプレースホルダとタイムスタンプ以外に使わない。壁紙が派手でも AA を下回らない値にしている。
  • Electron で必要な変更: titleBarStyle: 'hiddenInset'、trafficLightPosition: {x:18,y:18}、vibrancy: 'sidebar' または 'under-window' + visualEffectState: 'followWindow'、transparent 系は使わず backgroundColor: '#00000000'。ドラッグ領域は -webkit-app-region: drag(ボタンは no-drag)。テーマは nativeTheme.themeSource と同期させる。
  • 移植: トークン名は既存の --bg / --panel / --fg / --st-* にそのまま対応。追加分は --glass*、--blur、--st-approval-fill/-ink、--radius-window/-panel。
